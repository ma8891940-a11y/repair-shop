# برنامج إدارة صيانة الموبايل — المرحلة 1

تطبيق PWA عربي (من اليمين لليسار) لإدارة محل صيانة موبايل. بيفتح على تسجيل الدخول، وبعده لوحة التحكم.

## اللي موجود في المرحلة 1
- تسجيل دخول بالإيميل وكلمة السر. أول حساب بيعمل محل ويبقى صاحبه (owner)، وصاحب المحل بيضيف موظفين (استقبال / فني) بدعوة.
- استلام جهاز: بحث عن العميل بالموبايل أو إضافة عميل جديد، بيانات الجهاز، الملحقات، العطل، الحالة الشكلية، تكلفة تقديرية، ورقم طلب تلقائي (`2026-0001`).
- حتى 6 صور لكل جهاز (الصورة بتتصغّر قبل الرفع).
- قائمة الأجهزة: بحث برقم الطلب أو الموبايل أو الاسم أو IMEI، وفلتر بالحالة. المتأخر بيظهر بالأحمر.
- 10 حالات وأزرار لتغييرها. كل تغيير بيتسجّل (القديمة، الجديدة، الموظف، الوقت).
- لوحة تحكم: أجهزة اليوم، تحت الصيانة، الجاهزة، المتأخرة (أكتر من 7 أيام)، وإيراد اليوم (لصاحب المحل بس).
- طباعة إيصال استلام حراري 80مم (فيه شروط الاستلام)، وفاتورة A4.
- ملاحظات داخلية للفريق، وتنبيه لو نفس الـ IMEI دخل المحل قبل كده.
- سجل نشاط لصاحب المحل بس، ما بيتعدلش ولا بيتحذف.
- اختصارات: `F1` لوحة التحكم، `F2` استلام جهاز، `F3` بحث في الأجهزة.

## تشغيل البرنامج على جهازك خطوة بخطوة

### 1) ثبّت البرامج دي مرة واحدة
- **Node.js 22 (LTS)** من https://nodejs.org
- **Git** من https://git-scm.com

### 2) نزّل الكود
افتح Terminal (على ويندوز: PowerShell) واكتب:
```bash
git clone https://github.com/ma8891940-a11y/repair-shop.git
cd repair-shop
npm install
```

### 3) اعمل مشروع Supabase
1. ادخل https://supabase.com واعمل حساب، وبعدين **New project**. اختار منطقة قريبة (Frankfurt مثلًا).
2. من القائمة الشمال ادخل **SQL Editor**، ودوس **New query**.
3. افتح الملف `supabase/migrations/0001_phase1.sql`، انسخ كل اللي فيه، الزقه، ودوس **Run**. لازم يقول Success.
4. اعمل نفس الخطوة للملف `supabase/migrations/0002_storage.sql`.
5. اعمل نفس الخطوة للملف `supabase/migrations/0003_shop_profile_realtime.sql`.
6. ادخل **Authentication** ثم **URL Configuration**، وخلّي **Site URL** هو `http://localhost:5173`.
7. **كود التأكيد من 6 أرقام:**
   1. ادخل **Authentication** ثم **Email Templates** ثم **Confirm signup**.
   2. انسخ محتوى الملف `supabase/templates/confirm.html` والزقه مكان القالب الموجود، واحفظ.
   - من غير الخطوة دي، الإيميل هيوصل فيه رابط بس من غير كود.

### 4) اكتب مفاتيح Supabase (بنفسك)
1. من Supabase: **Project Settings** ثم **API**. هتلاقي **Project URL** و **anon public key**.
2. في فولدر المشروع اعمل نسخة من `.env.example` باسم `.env.local`:
   - ويندوز: `copy .env.example .env.local`
   - ماك/لينكس: `cp .env.example .env.local`
3. افتح `.env.local` واكتب القيمتين بعد علامة `=`.
4. **ممنوع تحط مفتاح `service_role`** في الملف ده أبدًا.

### 5) شغّل
```bash
npm run dev
```
افتح http://localhost:5173 في Chrome أو Edge، ودوس **"أول مرة؟ اعمل حساب جديد"**. هيوصلك إيميل تأكيد: دوس على الرابط، وارجع سجّل دخول.

### 6) ثبّته كتطبيق
في Chrome أو Edge هتلاقي علامة تثبيت في شريط العنوان، أو من القائمة ⋮ اختار **تثبيت "إدارة الصيانة"**. بعد كده يفتح في نافذة لوحده زي أي برنامج.

> ملحوظة: النسخة دي بتشتغل وهي `npm run dev` شغّال. التشغيل الدائم (رفع البرنامج على استضافة أو تغليفه كبرنامج كمبيوتر) خطوة جاية.

## الطباعة
- **إيصال 80مم:** في نافذة الطباعة اختار الطابعة الحرارية، والمقاس 80mm، والهوامش "بلا" (None).
- **فاتورة A4:** اختار الطابعة العادية والورق A4.

## الاختبارات
```bash
npm test
```
اختبارات الحسابات (القروش، الموبايل، IMEI، الحالات، لوحة التحكم، التواريخ).

```bash
npm run test:db
```
اختبارات الأمان على قاعدة بيانات مؤقتة (عزل المحلات، الصلاحيات، سجل النشاط، منع الحذف). محتاجة PostgreSQL 16 متثبّت، وما بتلمسش قاعدة البيانات الحقيقية.

## اختبارات القبول (جرّبها بنفسك)
1. اعمل حساب جديد ← اكتب اسمك واسم المحل ← تظهر لوحة التحكم.
2. من **الإعدادات** غيّر اسم المحل وشروط الاستلام ← احفظ.
3. من **المستخدمين** ابعت دعوة لموظف استقبال وفني. افتح نافذة متصفح خاصة (Incognito) واعمل حساب بإيميل الفني ← لازم يدخل على محلك.
4. **استلام جهاز** (`F2`): اكتب رقم موبايل ← بحث ← عميل جديد ← كمّل البيانات، وارفع صورتين ← احفظ ← لازم يظهر رقم طلب زي `2026-0001`.
5. استلم جهاز تاني بنفس الـ IMEI ← لازم يظهر تنبيه "الجهاز ده دخل المحل قبل كده".
6. اطبع **إيصال 80مم** ← لازم تظهر شروط الاستلام في آخره.
7. غيّر الحالة: جاري الفحص ← جاري الصيانة ← تم الإصلاح ← جاهز للاستلام ← حاول تسلّم ← لازم يطلب التكلفة النهائية الأول. اكتبها وسلّم.
8. لوحة التحكم ← "إيراد اليوم" = التكلفة النهائية للجهاز اللي سلّمته.
9. اطبع **فاتورة A4** ← فيها الإجمالي ومدة الضمان.
10. ادخل بحساب الفني ← ما بيشوفش أسعار ولا أسماء عملاء ولا سجل النشاط، وما يقدرش يسلّم جهاز.
11. **سجل النشاط** ← تلاقي تعديل التكلفة بالقيمة قبل وبعد.
12. اعمل حساب لمحل تاني ← ما يشوفش أي جهاز من محلك.

## هيكل المشروع
- `src/lib/` الحسابات والقواعد (مع اختباراتها في `lib.test.ts`)

- `supabase/migrations/` قاعدة البيانات والصلاحيات (RLS)
- `tests/db/` اختبارات الأمان على قاعدة البيانات
