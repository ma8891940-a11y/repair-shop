## 6. تقني
- **من Git Bash:** `;` بعد أمر فشل بيكمّل، و`set -e` مش مضمون مع `npm`. اربط كل حاجة لحد الـ push بـ `&&`. (حصل مرتين إن كود فاشل أو ناقص اتدفع وضاعت تشغيلة.)
- heredoc و`sed`/`perl` في Bash بيحوّلوا `\\` لـ `\`: أي سكريبت فيه regex أو عربي يتكتب بـ Write.
- حدود الموظفين: الخطة المجانية 5، فاختبار بخمس أدوار محتاج خطة من غير حد (شوف `stockCount.test.ts`).
- الدالة الجديدة: آخر تعريف بيتنسخ بسكريبت من كل الـ migrations، والمراجعة المستقلة قبل الـ push عشان تبقى تشغيلة واحدة.
- اختبارات معيّنة: `gh workflow run quality.yml --ref <فرع> -f specs="tests/e2e/a.spec.ts" -f projects='["desktop-dark","mobile-light"]'`.
- **من Git Bash:** تعديل بـ heredoc طويل فيه نص عربي وعلامات اقتباس بيتكسر. اكتب السكريبت بـ Write وشغّله، وابدأ السلسلة بـ `set -e` (حصل إن تعديل فشل والـ commit والتشغيل كمّلوا).
- commit بـ `-c user.name=Claude -c user.email=noreply@anthropic.com` (مفيش هوية git على الجهاز).
- بعد أي migration: `npm run db:setup-file` (بقى شغال على ويندوز).
- أي action جديد في `audit_log`: `audit.actions` و`audit.sentence`، و`name` في `after` عشان الجملة تبيّن الصنف.
- ملاحظة القيد (`memo`) بتتطبع على فاتورة العميل: ما تحطش فيها كلام داخلي.
