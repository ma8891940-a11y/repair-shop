# مهام Codex

- كل مهمة في ملف: `codex-<رقم من 3 خانات>-<اسم>.md`.
- كل ملف فيه:
  - المطلوب بالظبط.
  - الملفات المسموح بيها بس.
  - الممنوع.
  - الاختبارات المطلوبة.
- Claude (مدير المشروع) هو اللي بيكتبها ويراجع نتيجتها، والحالة في جدول `PROGRESS.md`.
- Codex بيشتغل في worktree منفصل على `codex/<اسم>`، ومن غير push. القواعد كاملة في `AGENTS.md`.
